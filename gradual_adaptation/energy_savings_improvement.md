# GCA 能耗收益提升技术报告

> 本文档说明如何将「渐进色适应 + 组合调光」方案的**预估 OLED 功耗收益**从约 6%（端部）提升至 **~30%（端部）/ ~16%（120s 时均）**，同时保持感知不可见（MetaM ≈ 5e-5）。

---

## 1. 原方案为何收益低

最初实现严格照搬 `gradual.md` 的"推荐配置"：

| 项 | 原值 | 后果 |
|----|------|------|
| 照明位移硬限制 | `|A(t) - D65| ≤ ΔT = 0.02 u'v'` | 白白放弃 ~2.5× 的色度漂移空间 |
| 只做色度偏移 | 无亮度/均匀调光 | 蓝色子像素省电已见顶，杠杆不足 |
| 120s 内线性渐变 | 时均 ≈ 峰值的一半 | 端部 ~6% → 时均仅 ~3% |

数值验证：原方案的 cf 数据集端部省电仅 ~6%，时均 ~3%。

---

## 2. 提升一：色适应感知调速（利用 ODE 追赶特性）

### 2.1 关键洞察

`gradual.md` 的优化约束是：

```
max_t ||A(t) - a(t)|| ≤ ΔT      # 感知失配 ≤ 5 JND
```

其中 `a(t)` 是用户**适应状态**，随照明演化：

```
a'(t) = k1 (k2 · A(t) - a(t))   # k1 适应速率，k2 适应完整度
```

原实现把约束误当作 `|A(t) - D65| ≤ ΔT`，**忽略了色适应会主动"追赶"照明**：只要漂移够慢，感知失配 `A - a` 始终保持在小范围，而照明 `A` 本身可以漂移远得多。

### 2.2 最大安全速度解析解（gradual.md 阶段三"快速求速方法"）

对恒定速度 `v`，ODE 的稳态追赶使失配近似为：

```
||A - a||(t) ≈ v/k1 + (1 - k2)·v·t
```

约束 `≤ ΔT` 在整个 `[0, t_max]` 成立，得到：

```
v_max = ΔT / (1/k1 + (1 - k2)·t_max)
```

代入 1.47 轨迹参数（k1=0.101, k2=0.685, ΔT=0.02, t_max=120）：

```
v_max = 0.02 / (1/0.101 + 0.315·120) ≈ 4.19e-4 u'v'/s
```

### 2.3 数值验证（ODE 逐帧积分）

对 `a'(t)=k1(k2·A−a)` 用 0.01s 步长做前向欧拉 120s 仿真：

| 量 | 值 |
|----|----|
| 最大感知失配 `max\|(A−D65)−(a−D65)\|` | **0.0187 ≤ ΔT=0.02** ✓ |
| 照明白点实际漂移 `\|A(120s)−D65\|` | **0.0503（≈ 2.5×ΔT）** |

即：**利用色适应追赶，同样的 5 JND 感知约束可换取 2.5 倍的色度漂移** → 端部色度省电从 ~6% 提升到 ~20%（GCA 单独）。

### 2.4 实现位置

- `trajectory.compute_max_adaptation_velocity()` —— v_max 解析解
- `trajectory.get_illuminant_{upvp,xyz}(..., adaptation_bounded=True)` —— 自动将速度钳制到 v_max，且不设 `|A−D65|` 硬限制
- `constants.DEFAULT_VELOCITY = 0.000419` —— 按 v_max 设定的推荐速度

## 3. 提升二：组合 GUD（渐进均匀调光）

`gradual.md` 明确提出组合优化：**GCA（变色）+ GUD（均匀调暗）可叠加省电达 ~31%，且无统计显著感知差异**。

```
dim(t) = 1 + (gud_target - 1) · min(t / gud_t_max, 1)
```

- 均匀调暗直接按比例降低所有子像素功耗 → 最直接的省电杠杆
- 与色度偏移正交，功耗损失可叠加
- 推荐 `gud_target = 0.85`（调暗 15%）：对亮度感知影响小，MetaM 保持 ~5e-5

### 实现位置

- `constants.GUD_ENABLED / GUD_TARGET / GUD_T_MAX`
- `GradualAdaptationImageOptimizer.process_frame()` —— GCA 后再乘 GUD 系数

## 5. 结论与后续调参建议

1. **色适应调速**是本方案收益的核心放大器：约束对象是感知失配而非绝对照明位移。
2. **GUD** 提供与色度正交的基线省电，且 MetaM 几乎不变。
3. 若需更高端部省电，可在 MetaM 约束下小幅调低 `GUD_TARGET`（如 0.8）或提高 `DELTA_T`（如 0.025），但需重新验证 MetaM。
4. 若感知余量紧张，可降低 `DELTA_T` 至 0.015，仍能获得约 3/4 的色度收益。
